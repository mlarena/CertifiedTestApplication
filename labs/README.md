# Лабораторные работы по PostgreSQL DBA

Набор из 66 лабораторных работ, основанных на курсах DBA1 «Администратор баз данных» и DBA2 «PostgreSQL. Настройка и мониторинг» (PostgreSQL Pro).

## Уровни

| Уровень | Кол-во | Фокус |
|---------|--------|-------|
| [Junior](junior/) | 16 | Базовые навыки: установка, psql, конфигурация, основы SQL, мониторинг таблиц |
| [Middle](middle/) | 18 | Архитектура: MVCC, VACUUM, WAL, статистика, производительность, блокировки |
| [Senior](senior/) | 17 | Администрирование: бэкапы, репликация, безопасность, расширение, локализация |
| [Master](master/) | 15 | Продвинутое: pg_upgrade, репликация, PITR, SSL, расширения, полный DBA-сценарий |

## Структура каждой лабораторной

1. **Цель** — что изучаем
2. **Теория** — краткое описание концепции
3. **Задание** — пошаговые инструкции
4. **Решение** — готовые команды с выводом
5. **Контрольные вопросы** — для самопроверки
6. **Дополнительное задание** — усложнённый вариант (опционально)

## Требования

- PostgreSQL 16 на Ubuntu (или аналогичный Linux)
- Пользователь `student` с правами суперпользователя
- Утилита `psql`

## Порядок прохождения

Рекомендуется проходить работы последовательно: Junior → Middle → Senior → Master. Внутри каждого уровня работы тоже идут по нарастающей сложности.
